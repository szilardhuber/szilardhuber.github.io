Delivered Apple projects, conducted requirement workshops at Cupertino HQ, mentored engineers to lead independently.

Grew organization 5→20 engineers across 3 teams. Site lead for Szeged R&D center. Built Cubby file sync engine with efficient change detection and conflict resolution. Delivered Join.me Windows Store launch app. Explored Cassandra, WebRTC for future products.

Built 5-person team, unified screen capture across LogMeIn Pro, RemotelyAnywhere, enabling Join.me launch without rebuilding core functionality. Created single reusable module from separate legacy codebases. Promoted to Engineering Manager after successful consolidation.

**2008 - 2010: Senior Software Engineer @ LogMeIn**

Developed bandwidth optimization for screen sharing. Designed rect-based caching system with offset detection for window movement, significantly reducing network traffic. CTO praised approach for simplicity and impact. Refactored screen capture into dedicated module.

**2007 - 2008: Software Engineer @ DSS Consulting**

Crisis management: entire dev team quit day 2. Became sole developer with active projects. Delivered Hungarian Financial Supervisory Authority project on time despite zero codebase knowledge. Recruited and integrated 4-person team within 6 months without missing deadlines.

**2004 - 2007: C++ Developer @ Graphisoft**

Developed ArchiCAD 2D components. Contributed to Teamwork functionality transforming single-user CAD into collaborative platform for large architecture firms. Cross-platform Mac/Windows development. First management role leading vendor team.

**2002 - 2004: Software Engineer @ PEC Corp**

First professional role. Built factory line integration modules connecting C++ software with camera-based QA systems. 2-month on-site deployment at manufacturing facility. Foundation in industrial software and cross-vendor collaboration.
